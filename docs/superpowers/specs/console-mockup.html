The ramp varies by luminance as well as hue, so it survives deuteranopia and greyscale. Navigation, links and selection use the single cool accent and never a severity colour — if nav were red, red would stop meaning "wake someone up".

5 · Topology canvas — a view of a reconciled model, not a drawing

Binding state is border geometry, never colour — solid = declared and discovered, dashed = declared but never enrolled, double = discovered and undeclared, the state the feature exists to surface. Severity is the only saturated colour on the canvas, so it is the only thing that draws the eye across a large graph.

6 · The nine states every view must define

Loading · first

Static skeleton matching final layout. No shimmer.

Loading · refresh

Content stays; hairline progress at region top. Numbers never blank.

Empty · no data

Says why, and offers the next action. Not the same screen as broken.

Empty · unconfigured

"0 agents enrolled" + the copyable enrol command.

Filtered to nothing

Shows active filters and a one-click clear.

Error

What failed, what still works, what to do. Never a bare status code.

Degraded

Names the impairment and what the data on screen therefore is.

Stale

Amber timestamp + last-successful time. Never old data shown as current.

Forbidden

Names the tier required and who grants it. Distinguishes revoked from never-had.
